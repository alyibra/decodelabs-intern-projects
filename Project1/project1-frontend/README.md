# Responsive Frontend Interface (Project 1)

A clean, mobile-first task manager interface built with pure HTML, CSS, and vanilla JavaScript. Designed for responsive use across mobile, tablet, and desktop, with a dark theme, priority tags, progress stats, and localStorage persistence.

**Features**

- Live task list: add, complete, and delete tasks
- Priority tags (High / Medium / Low) with color coding
- Stats bar showing total, completed, pending, and progress percentage
- Animated hero preview card and sticky navbar with hamburger menu for mobile
- Dark theme and mobile-first responsive layout
- Persistence using `localStorage` (tasks survive page reloads)

**Tech stack**

- HTML5
- CSS3 (responsive, mobile-first)
- Vanilla JavaScript (ES2020+)

**How to run**

1. Open the project folder `project1-frontend` in your file manager.
2. Double-click or open `index.html` in any modern browser (Chrome, Firefox, Safari, Edge).

No build tools or servers are required.
